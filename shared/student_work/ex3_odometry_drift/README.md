# Exercise 3: Odometry Drift - Student Submissions

This directory contains student submissions for Exercise 3: Odometry-Only Waypoint Navigation.

## Submission Requirements

Each student should submit:

1. **drift_analysis.md** - Main report analyzing odometry drift
2. **trial_data.csv** (optional) - Raw experimental data
3. **screenshots/** (optional) - RViz visualizations showing drift

## Directory Structure

```
ex3_odometry_drift/
├── README.md (this file)
└── <student_name>/
    ├── drift_analysis.md
    ├── trial_data.csv (optional)
    └── screenshots/ (optional)
```

## Example Submission

```
ex3_odometry_drift/
└── john_doe/
    ├── drift_analysis.md
    ├── trial_data.csv
    └── screenshots/
        ├── trial1_final_position.png
        └── rviz_drift_visualization.png
```

## Grading Criteria

- Experimental data (4+ trials): 30%
- Error analysis (calculations, insights): 25%
- Understanding (drift causes explained): 25%
- Written quality (clarity, organization): 20%

**Total**: 100 points
**Passing**: 60 points
